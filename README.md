# 🎲 یونو آنلاین — UNO Telegram Mini App

بازی آنلاین یونو به صورت Telegram Mini App با طراحی فارسی راست‌چین، فونت وزیرمتن و انیمیشن‌های حرفه‌ای.

## ✨ ویژگی‌ها

- **آنلاین و لحظه‌ای**: Socket.IO — بازی همزمان با دوستان
- **اتاق اختصاصی**: هر حساب کاربری اتاق مخصوص خودش را دارد
- **دعوت با کد یا لینک**: کد ۵ حرفی یا لینک `t.me/<bot>?startapp=CODE`
- **۲ تا ۶ بازیکن**
- **قوانین رسمی یونو**: ۱۰۸ کارت، رد/معکوس/+۲/وایلد/+۴، برداشتن یک کارت، یونو و جریمه، محاسبه امتیاز
- **طراحی اپیک**: SVG دست‌ساز برای کارت‌ها، انیمیشن پخش و پرتاب کارت، کانفتی برنده
- **ربات تلگرام**: شروع بازی از داخل ربات

## 🚀 اجرا

```bash
npm install
BOT_TOKEN=<telegram-bot-token> WEBAPP_URL=https://your-domain.up.railway.app npm start
```

### متغیرهای محیطی

| متغیر | توضیح |
|---|---|
| `PORT` | پورت سرور (پیش‌فرض 3000 — روی Railway خودکار) |
| `BOT_TOKEN` | توکن ربات تلگرام |
| `WEBAPP_URL` | آدرس Mini App (برای دکمه وب‌اپ ربات) |

## 🎮 نحوه بازی

1. ربات را باز کنید و «شروع بازی» را بزنید
2. اتاق اختصاصی شما ساخته می‌شود
3. کد اتاق یا لینک دعوت را برای دوستان بفرستید
4. میزبان بازی را شروع می‌کند — موفق باشید! 🏆
